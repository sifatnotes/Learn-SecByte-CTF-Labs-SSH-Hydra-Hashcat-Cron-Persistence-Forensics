## Learning Path

A practical progression through these cybersecurity labs is:

1. Begin with **Linux user discovery** and basic system investigation.
2. Study **cron and persistence artifacts**.
3. Move into **SSH keys and authentication trails**.
4. Learn the security concepts behind **wordlists and password testing**.
5. Explore **Hydra** in an authorized lab environment.
6. Study **Hashcat rules and password mutations**.
7. Investigate **hidden developer messages** and suspicious artifacts.
8. Finish with **backdoor forensics and persistence hunting** to connect red-team activity with incident response.

## How to Use the Labs

Use these exercises only in authorized lab environments.

Recommended workflow:

1. Read the lab objective before starting.
2. Identify the relevant system, account, authentication, or persistence artifact.
3. Perform controlled reconnaissance within the provided environment.
4. Document findings such as users, SSH configuration, cron entries, hashes, files, or suspicious artifacts.
5. Investigate the challenge using only the authorized lab target.
6. Record the security impact and relevant indicators.
7. Consider defensive controls such as strong authentication, SSH hardening, secure password policies, persistence monitoring, and file-integrity checks.

Password-testing and hash-recovery exercises should be performed only against intentionally provided lab data or systems for which you have explicit authorization.
